# Mesto. Работа с сервером

Проектная работа курса Яндекс Практикума «Веб-разработка»: интерактивная страница Mesto,
подключённая к учебному API `nomoreparties.co`.

## Возможности

- Загрузка профиля и карточек с сервера (`Promise.all`)
- Редактирование имени и описания профиля (`PATCH /users/me`)
- Обновление аватара (`PATCH /users/me/avatar`)
- Добавление новой карточки (`POST /cards`)
- Удаление своей карточки с подтверждением (`DELETE /cards/:id`), корзина видна только у владельца
- Постановка и снятие лайков (`PUT`/`DELETE /cards/:id/likes`) со счётчиком
- Попап статистики карточки: дата создания, количество лайков, список пользователей, лайкнувших карточку
- Индикация процесса сохранения на кнопках форм («Сохранение...», «Создание...»)
- Закрытие попапов кликом по оверлею и клавишей Escape

## Технологии

- HTML5, CSS3 (БЭМ)
- JavaScript (ES6-модули, промисы, Fetch API)
- [Vite](https://vitejs.com/) — сборка проекта

## Запуск

```bash
npm install    # установка зависимостей
npm run dev    # запуск dev-сервера
npm run build  # production-сборка в папку dist
```

## Деплой

Сборка выкладывается на GitHub Pages автоматически через GitHub Actions
(`.github/workflows/deploy.yml`): при пуше в `main` проект собирается и результат
публикуется в отдельный публичный репозиторий Pages.
